# 实验3 CSS布局实战——导航菜单
## 实验说明
本实验严格遵循要求：**不修改HTML结构，全部布局与交互由CSS实现**。

文件列表：
1. 一级菜单.html：水平一级导航菜单，使用flex实现横向排列，hover实现背景高亮。
2. 二级菜单.html：下拉导航，利用`position:relative/absolute`父子定位，结合`:hover`伪类完成二级菜单显示隐藏。

用到技术点：
1. CSS flex布局实现菜单项水平排列
2. 盒模型padding控制内边距与点击区域
3. position相对+绝对定位实现下拉菜单
4. :hover伪类实现鼠标悬停交互
5. 后代选择器区分一级、二级菜单样式
